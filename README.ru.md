# Калькулятор мягких окон

[Открыть онлайн-калькулятор](https://beynda.com/tools/soft-window-calculator/). Демо считает в браузере и создаёт PDF без сбора контактных данных.

Калькулятор мягких окон и дверей из гибкой ПВХ-плёнки, подготовленный Beynda.

[English documentation](README.md)

Девять форм окон, прямоугольные двери, фурнитура по сторонам, чертёж, детализация стоимости, печать и PDF. Технический черновик сохраняется в браузере. PHP-сервер повторно рассчитывает стоимость, проверяет заявки и предоставляет админку.

## Быстрый запуск

Требуется Node.js 24 или новее. Дополнительные npm-зависимости для запуска не нужны.

```sh
npm run dev
```

Откройте адрес из терминала. В верхней панели выберите «Русский». Русская версия использует сантиметры и рубли. Английская открывается по умолчанию с дюймами и USD; можно выбрать сантиметры и EUR. Размеры сохраняются при переключении. Контактные поля после подтверждения очищаются и не попадают в локальный черновик.

Демонстрационный сервер имитирует отправку и архив, держит записи в памяти и не отправляет письма. Используйте тестовые контакты. Его ответ на отправку содержит заглушку PDF; кнопка «Скачать PDF» создаёт настоящий документ в браузере.

## Тарифы и единицы

Цены являются примерами, а не рыночными предложениями. Перед использованием задайте собственные тарифы в `storage/config.json`.

- `currency`, `tariffs`, `vat`: основной профиль RUB.
- `marketRates.USD`: независимые тарифы и налоги для USD.
- `marketRates.EUR`: независимые тарифы и налоги для EUR.

Профили валют доступны в JSON-редакторе админки. Конвертации по валютному курсу нет. USD и EUR округляются до центов, RUB сохраняет округление до целого рубля. Сервер использует свои тарифы, клиент не может передать готовую стоимость.

Размеры внутри ядра хранятся в сантиметрах. Дюймы пересчитываются по точному соотношению 1 дюйм = 2,54 см. Тарифы на материал задаются за квадратный метр, линейные тарифы за метр во всех профилях. PDF и печатная версия сохраняют язык и единицы своего расчёта.

## Проверки и сборка

```sh
npm test
npm run build
```

PHP-тестам требуется PHP 8.1 или новее. Без PHP соответствующие проверки пропускаются. Для браузерных сценариев нужны Python, Playwright, Pillow и pypdf.

Готовый пакет находится в `deployment/dist/window-calculator/`. Изменяйте исходники и повторяйте сборку.

## Установка

См. [инструкцию установки](docs/INSTALL.md). Просмотр архива, PDF и редактирование требуют входа администратора; изменения защищены CSRF-токеном. Настройте ADMIN_PASSWORD_HASH, закройте прямой доступ к storage и используйте HTTPS. На целевом сервере проверьте авторизацию, PHP, письма и интерфейс.

По умолчанию письма записываются только как технические метаданные в безопасном log-режиме. Реальную отправку нужно настраивать отдельно. Переменные среды перечислены в `.env.example`; PHP не загружает этот файл автоматически. Не публикуйте секреты.
